LakuenCast v0.3.4: Verbinden per Code

- **6-stelliger Code**: Im LakuenCast-Fenster steht neben dem QR-Code jetzt ein Code wie „482 913“. Damit verbindest du dich direkt in der Home-Bildschirm-App, ganz ohne Kamera.
- **Neuer Verbinden-Bildschirm**: Ist keine Verbindung da oder ist sie abgelaufen, zeigt die App ein Ziffernfeld. Der Code wird automatisch abgeschickt, sobald alle 6 Ziffern drin sind.
- Code und QR-Code gelten nur einmal und wechseln nach jedem Verbinden. Nach 5 falschen Versuchen wechselt der Code, und es gibt 30 Sekunden Pause.
